# Validating and squaring user input

Hey there! This problem might be a bit unpredictable, but give it a go and let us know how you do!
Write a program that scans an integer from the user. If the scanned integer is negative, print "Invalid input!", otherwise print the square of the integer.
Sample Input 1:

-5

## Sample Output 1:

Invalid input!

## Sample Input 2:

0

## Sample Output 2:

0
